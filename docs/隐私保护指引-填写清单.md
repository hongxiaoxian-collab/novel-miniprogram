# 微信公众平台「用户隐私保护指引」填写清单

> **配套说明**：这份是给你在 **mp.weixin.qq.com 后台**勾表单用的，和《隐私政策.md》是两件事，**两个都要做**：
> - 后台的《用户隐私保护指引》—— 微信官方要求，不填无法通过代码审核（2023-09-15 起强制）；
> - 小程序内的《隐私政策》全文 —— 《个人信息保护法》要求，给用户看的。
>
> 后台表单的选项名称会随微信版本微调，**以你实际看到的为准**，本清单给的是对应关系。

---

## 一、填写入口

```
mp.weixin.qq.com → 登录 → 左侧「设置」→「服务内容声明」
→「用户隐私保护指引」→ 点「更新」→ 按下面逐项勾选 → 提交
```

提交后需要**等微信审核**（通常 1–2 个工作日），审核通过后才能在代码里启用隐私授权。

## 二、必须勾选的收集项（对照本项目）

| 后台勾选项 | 本项目是否要勾 | 原因 |
|---|---|---|
| **微信身份标识（OpenID、UnionID）** | ✅ **必勾** | 你一旦调用 `wx.login` 就会拿到 openid。这是本项目登录的最小集合 |
| **相册（仅写入）权限** | ✅ **必勾** | `pages/intro/intro.js` 调了 `wx.saveImageToPhotosAlbum`（保存封面图）。不勾＝声明与代码对不上，提审必被打回 |
| **剪切板** | ✅ **必勾** | `utils/clipboard.js` 调了 `wx.setClipboardData`。**官方把 set / get 都归到「读取你的剪切板」一项**，所以写剪贴板也要声明 |
| **昵称 / 头像** | ❌ **不勾**（当前版本没做） | 代码里没有 `getUserProfile` / `chooseAvatar`。等真做了头像昵称再回来勾 |
| **手机号** | ❌ **不勾**（当前版本没做） | 代码里没有 `getPhoneNumber`。多勾会在提审时被要求解释 |
| 位置信息 / 通讯录 / 好友列表 / 微信运动 / 摄像头 / 麦克风 / 蓝牙 / 日历 / 设备标识（IMEI、MAC 等） | ❌ **全部不勾** | 本项目没有这些功能。勾了反而要在提审时解释为什么需要，增加被打回的概率 |
| **微信同声传译插件（第三方插件信息）** | ❌ **不勾 / 删掉** | 项目里**没有接入任何插件**（`app.json` 无 `plugins` 字段、代码无 `requirePlugin`）。若后台有这条，去「设置 → 第三方设置 → 插件管理」把该插件删掉 |
| **用户主动输入的文本内容**（若后台有此项，或填在"其他"里） | ✅ 建议勾 / 补充说明 | 书名、笔名、作品正文、大纲是用户主动输入的，属个人信息，必须披露 |

### 用途文案（直接复制粘贴，别写"用于改善用户体验"这种空话）

**相册（仅写入）** 的用途栏：

```
在你点击「保存封面」时，把生成的封面图写入你的相册。我们不读取你相册中的照片。
```
若输入框字数受限，用短版：`保存生成的封面图到你的相册，不读取相册已有照片`

**读取你的剪切板** 的用途栏：

```
在你点击「复制」按钮时，把书名、简介或章节正文写入剪贴板，方便你粘贴到创作平台。我们不读取你剪贴板中的内容。
```
若输入框字数受限，用短版：`复制书名、简介或正文时写入剪贴板，不读取剪贴板内容`

**手机号**、**微信昵称/头像** 两行：代码里没有对应接口，**点右侧 ⊖ 整行删掉**，用途栏不用填。

> ⚠️ 用途栏里**绝对不要出现代码路径**（如 `pages/intro/intro.js` 调了 `wx.…`）——这段文字会直接展示给用户，写代码路径既看不懂，审核员也会判为"未如实说明用途"。
>
> 审核员看的是**具体、可核对**的描述：什么场景触发、写了什么、承诺不做什么。上面两句都落到了代码里的真实按钮上，对得上就没问题。

## 四、代码侧必须做的 4 件事

### 1）`app.json` 开启隐私校验

```json
{
  "window": { "...": "..." },
  "__usePrivacyCheck__": true
}
```

### 2）调用隐私接口前先弹授权

官方的做法是——**在真正用到隐私接口之前**先问一次：

```js
// utils/privacy.js
export function ensurePrivacy() {
  return new Promise((resolve) => {
    if (!wx.getPrivacySetting) return resolve(true); // 老版本基础库，跳过
    wx.getPrivacySetting({
      success: (res) => {
        // res.needAuthorization: false 表示用户已同意或还没启用隐私协议
        if (!res.needAuthorization) return resolve(true);
        wx.requirePrivacyAuthorize({
          success: () => resolve(true),
          fail: () => resolve(false), // 用户拒绝：不要强行调用隐私接口
        });
      },
      fail: () => resolve(true),
    });
  });
}
```

在 `app.js` 的 `onLaunch` 里调一次即可：

```js
onLaunch() {
  ensurePrivacy().then((ok) => { this.globalData.privacyOk = ok; });
}
```

> 也可以用官方组件免写 JS：`<button open-type="agreePrivacyAuthorization">同意隐私协议</button>`

### 3）提供「撤回同意」和「查看隐私协议」入口

```js
wx.openPrivacyContract({});   // 打开你在后台配置的那份指引
```

微信小程序提供统一的「隐私授权」页面（右上角 `...` → 设置），用户可在那里自行撤回。你只需在「我的」页给一个跳转入口。

### 4）后端配套（这个是硬要求，容易漏）

| 动作 | 说明 |
|---|---|
| **openid 不要写进日志** | 现在日志里打印请求参数的地方要检查一遍 |
| **新增「注销账号」接口** | 删除该 openid 下全部作品、章节、体检记录。《个保法》要求必须能删 |
| **新增「导出我的数据」接口** | 对应"查阅、复制"权。好消息：你已有 `GET :id/export`，按作品导出即可 |
| **不要在前端明文存 openid** | 存 `wx.setStorageSync` 无所谓本地，但别写进 `globalData` 后到处传 |

## 五、提审时的 3 个常见打回点

1. **类目没填对** —— 创作工具类小程序建议选「工具 → 效率」或「文娱 → 资讯/小说」；AI 生成功能可能要求补充 **「深度合成 / 生成式 AI」** 相关类目与备案，这个务必先在后台确认，否则必被打回。
2. **隐私指引和代码里实际调用的接口对不上** —— 勾了手机号却没做授权弹窗，或代码调了 `getUserProfile` 却没勾"昵称/头像"，都会被判"不一致"。
3. **AI 内容安全** —— 生成式内容必须有**内容安全审核**（关键词过滤 + 可选 `msgSecCheck`），否则提审会直接拒绝。你现在的 Coze 输出是直出到小程序的，这块需要补。

## 六、我的建议

这个小程序目前是**你自己用的写作工具**。合规成本最低的组合是：

- **身份**：只调 `wx.login` 拿 openid 做数据隔离 → 后台只勾「微信身份标识」。
- **相册（仅写入）+ 剪切板**：这两个是**功能带来的，躲不掉**——只要你还要"保存封面"和"复制书名/正文"，就必须声明。好在它们都是**用户主动点击才触发**，不是后台静默收集，用途写实了就不麻烦。
- **头像昵称、手机号**：❌ 现在别加。每多一项，隐私指引、授权弹窗、提审解释的工作量都要翻倍。

**判断口诀**：代码里 `grep` 得到的隐私接口 ⇔ 后台勾选项，两边必须**一一对应**。
多了叫"超出必要范围"，少了叫"未如实声明"，两种都会被审核打回。

自查命令（在你项目根跑一次就清楚）：

```bash
cd miniprogram
grep -rn "saveImageToPhotosAlbum\|saveVideoToPhotosAlbum\|setClipboardData\|getClipboardData\|getPhoneNumber\|getUserProfile\|chooseAvatar\|getLocation\|chooseImage\|chooseMedia\|startRecord\|getRecorderManager" --include=*.js .
```

命中的接口 ↔ 后台必须勾；没命中的一律别勾。
