## 〇、先记住一件事

后台那句「**小程序涉嫌违规**」是**所有**搜索限制的**统一提示语**，它**不告诉你具体原因**。  
真正的原因只写在后台三个地方。**不要凭印象猜，先逐项查。**

---

## 一、先定位原因（三个地方，约 5 分钟）

### ① 通知中心 / 站内信　★最重要

- 路径：`mp.weixin.qq.com` 登录 → **左下角「通知中心」** → 逐条翻近期通知
- 重点看三类：**违规处罚** / 交易结算 / 订单发货
- 若有违规通知，通知正文会写明：**违规类型 + 违反的规范条款 + 整改要求 + 申诉入口**
- 判读：
  - 有「违规处罚」通知 → 走 **情况 B**（整改 + 申诉）
  - 有「注销备案和限制服务能力」通知 → 走 **情况 A**（重新备案，自动恢复）

### ② 小程序备案

- 路径：`设置 → 基本设置 → 小程序备案`
- 需显示「**已备案**」
- 若显示：备案被注销 / 信息不准确 / 待变更 → **这就是原因**（官方口径：约 90% 的搜索限制由备案问题导致）

### ③ 微信认证

- 路径：`设置 → 微信认证`（或「基本设置」中的认证状态）
- 需显示「**已认证**」且在**有效期内**
- ⚠️ **本账号重点核对项**：认证日期 **2025-08-07**，微信认证为**年度**性质、需年审；  
  若年审未完成 → 会造成「涉嫌违规并限制被搜索」。**两年了，务必确认是否已过期。**

### 顺手看两眼

- `版本管理`：线上版本是否为「已发布」
- `设置 → 基本设置`：是否误开了「暂停服务」

## 三、本项目特有的两个必查项（与上面并行，不查会被再拒）

### 3.1 内容与「介绍 / 类目」不符　← 高嫌疑

- **现状**：小程序介绍写的是「蓝牙智能物联，蓝牙智能锁，蓝牙AI」，  
  主营类目是「**工具 > 设备管理**」，但**小程序实际功能是 AI 写小说**。
- 这在官方定义里属于「**实际业务与备案不符**」，是明确列出的违规类型。
- **动作**：
  1. 改小程序**介绍**：如实写「AI 辅助小说创作工具」之类，别再挂智能锁

- 提供 AI 生成内容却没有对应类目，等于「**运营业务没有相关资质**」。

  - 备案编号：`网信算备440305295988701230071号`
  - 服务有效期至：**2027-04-08**（提交类目时「资质有效期」填这个日期，**不要选"长期有效"**）
- **动作**：按 `docs/AI合规整改-审核提交流程.md` §5.4 提交类目（内部预估 1–3 个工作日，可勾加急）。
