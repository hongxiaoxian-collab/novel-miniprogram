## 二、开通登录：3 步（不做就一直按游客跑）

> ✅ **2026-10-06 已完成**：AppSecret 已拿到并写入服务器 `.env`，`AUTH_SECRET` 用强随机串生成，后端已重启。
> 实测 `GET /auth/plans` 返回 `enabled: true`，登录通道已启用。用假 code 调登录，微信回 `40029 invalid code`
> （说明密钥被微信正确接受——若密钥错会回 40013/40125，若网络不通会超时）。
> 现在只差把 v1.0.2 提审发布，用户端才会看到「我的」页。

### 第 1 步：拿 AppID 和 AppSecret

```
mp.weixin.qq.com 登录 → 左侧「开发」→「开发管理」→「开发设置」→「开发者ID」
```

- **AppID**：直接可见（`wx879e614f17e6d355`）
- **AppSecret**：点「生成」或「重置」。**只在生成时显示一次**，立刻复制保存，离开页面就再也看不到，只能重置

### 第 2 步：填到服务器

服务器文件：`C:\erp\novel-backend\.env`

```
WX_APPID=你的AppID
WX_APP_SECRET=你的AppSecret
AUTH_SECRET=随便敲一段长随机字符串
```

`AUTH_SECRET` 用来给登录凭证签名，**一定要改**，别留空（留空会用默认值，等于谁都能伪造登录）。

### 第 3 步：重启后端

改完 `.env` 必须重启才生效。让 AI 帮你重启，或在服务器上重启对应服务。

**验证是否生效**：小程序首页进「我的」——
- 显示 `***xxxx`（openid 后四位）+ 等级 = 登录成功
- 显示「游客（未登录）」= 后端没读到密钥，检查上面两行有没有填对、有没有重启

## 三、隐私合规：必须完成的 4 件事

登录一开，以下就成硬义务，缺一件提审会被打回：

1. **后台配置《用户隐私保护指引》**
   mp → 设置 → 服务内容声明 → 用户隐私保护指引 → 更新 → 至少勾 **「微信身份标识（OpenID、UnionID）」** → 提交 → 等审核（1–2 个工作日）。
   *只勾这一项就够，别多勾*——勾了手机号却没做授权弹窗，会被判"指引与实际不符"。

2. **小程序内放《隐私政策》全文**
   把 `docs/隐私政策.md` 里 `【】` 占位符替换成真实主体信息后，放到「我的」页可点开的位置。
   当前「我的 → 查看隐私政策」调的是微信官方指引页（第 1 步审核通过后才打得开）。

3. **保留注销入口** —— 已做好，别删。这是《个人信息保护法》要求，删了属于违规。

4. **AI 内容安全**（和登录无关，但提审必查）
   Coze 生成的内容目前直出，没过内容安全检测。提审前要接 `msgSecCheck`，否则大概率被拒。

## 五、VIP 充值：三个方案（这里有个硬风险，先看完）

### ⚠️ 先说风险：iOS 端不能在小程序里卖虚拟内容

你这个产品卖的是 **AI 生成服务 = 虚拟内容**。微信的规则是：

- **安卓端**：小程序内可以用微信支付卖虚拟内容
- **iOS 端**：**不允许**小程序内虚拟支付（苹果的规则：App 内买虚拟商品必须走 Apple IAP，而小程序里做不了 IAP）
- 微信会拦截 iOS 端的虚拟支付调用

**这意味着：如果只做"小程序内微信支付"，你的 iPhone 用户会付不了钱。**

另外两个前置条件：
- 开通微信支付必须是**企业或个体工商户**主体，**个人主体开不了**
- 收费功能还要求小程序**服务类目**匹配，类目不对提审直接拒

### 方案对比

| 方案 | 怎么做 | 优点 | 缺点 |
|---|---|---|---|
| **A. 兑换码 / 人工开通**（推荐先用这个） | 你给我名单，我直接在库里把账号调成 VIP；或生成一串兑换码，用户输入即开通 | 零合规风险、零手续费、零审核周期、iOS/安卓都能用、今天就能上线 | 需要人工发货，量大时麻烦 |
| **B. 小程序内微信支付** | 接 `wx.requestPayment`，安卓可用 | 全自动，用户体验好 | iOS 付不了；要商户号 + 企业主体 + 类目；虚拟支付要单独申请开通 |
| **C. 公众号 / H5 网页收款** | 付费入口放在公众号菜单或 H5，小程序只校验权益 | 绕开 iOS 限制，合规路径成熟 | 需要公众号（且最好认证服务号），用户路径长一点 |

**我的建议**：先走 **A** 把 VIP 跑起来（你现在的量，人工完全够），等确认了主体资质、类目和 iOS 怎么处理，再决定上 B 还是 C。数据库里 `Order` 表已经留了 `channel` 字段，`manual` / `wxpay` 都支持，将来切换不用改数据结构。

## 七、常见问题

**Q：不配密钥，小程序还能用吗？**
能，完全一样。`enabled: false` 时前端静默跳过登录，一个功能都不受影响。

**Q：登录后老作品会不会丢？**
不会。登录前建的作品 `userId` 是空的，登录后照样显示。只有**新建**的作品才归到名下。

**Q：换手机/重装微信，作品还在吗？**
在。数据存在服务器，靠 openid 识别，跟设备无关。

**Q：openid 会泄露吗？**
前端拿不到 openid，只拿一个有时效的 token。openid 存在服务器数据库里，不外传、不写日志。

**Q：想彻底不要登录了？**
把服务器 `.env` 里 `WX_APPID`/`WX_APP_SECRET` 删掉重启即可，功能自动回到游客模式，数据不丢。
