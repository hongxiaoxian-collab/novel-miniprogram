## 四、我们如何存储和保护您的个人信息

1. **存储地域**：您的个人信息存储于**中华人民共和国境内**的服务器。
2. **存储期限**：
   - 账号存续期间持续保存，用于为您提供服务；
   - 您删除某部作品后，该作品及其章节、体检报告将被**立即删除**；
   - 您注销账号后，我们将在 **15 个工作日**内删除或匿名化处理您的全部个人信息（法律法规要求留存的除外，如网络日志留存 6 个月）。
3. **安全措施**：
   - 数据传输全程使用 HTTPS 加密；
   - 服务器启用访问控制与密钥登录（SSH），关闭密码登录；
   - 数据库仅内网访问，不外网暴露端口；
   - 对员工实行最小权限管理与保密培训。
4. **安全事件处置**：若不幸发生个人信息泄露等安全事件，我们将按法律法规要求**立即启动应急预案**，并通过小程序站内消息、短信或公告方式及时告知您事件的基本情况、影响范围、已采取的处置措施和您的应对建议。

> 提示：互联网环境并非绝对安全，请您妥善保管微信账号，不要将账号出借他人。如发现账号异常，请按第九节方式联系我们。

依据《个人信息保护法》，您对自己的个人信息享有以下权利，我们承诺在**15 个工作日内**予以响应：

| 权利 | 说明 | 行使方式 |
|---|---|---|
| **查阅、复制** | 查看我们持有的您的个人信息，并要求提供副本 | 小程序内「我的 → 账号与安全」；或联系我们 |
| **更正、补充** | 发现信息有误或不完整时要求更正 | 直接在对应页面修改；或联系我们 |
| **删除** | 删除单部作品，或删除全部个人信息 | 作品列表长按删除；「我的 → 注销账号」 |
| **撤回同意** | 撤回已授予的授权（如头像昵称、手机号） | 「我的 → 隐私设置 → 撤回授权」；撤回后不影响撤回前基于同意的处理 |
| **注销账号** | 彻底注销，我们将删除或匿名化全部信息 | 「我的 → 注销账号」，注销**不可恢复**，请先导出作品 |

**关于注销的重要提醒：** 注销后您的全部作品、章节、大纲、体检记录将被永久删除且无法找回。请在注销前使用「导出」功能备份您的作品。
