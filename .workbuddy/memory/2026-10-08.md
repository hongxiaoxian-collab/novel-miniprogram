  ② **云开发服务端：云函数 / 云托管中用 `wx-server-sdk`、`@cloudbase/node-sdk`、`@cloudbase/js-sdk`**；

## 12. 云函数形态定案：HTTP 云函数（Web 函数）· 一码双形态（2026-10-08）

| 对比项 | 普通云函数（事件） | HTTP 云函数（Web） |
|---|---|---|
| 入参 | 固定 `event` / `context` | 原生 HTTP Request / Response |
| 端口监听 | 不需要 | **必须监听 9000** |
| 启动文件 | 无 | **`scf_bootstrap`（必需）** |
| 并发 | 单实例单请求 | 单实例多并发 |

**scf_bootstrap 硬要求**（微信官方《HTTP 云函数》文档）
- 文件名固定 `scf_bootstrap`（无扩展名）；**LF 换行**（不能 CRLF）；**755/777 可执行权限**；
  首行必须是 `#!/bin/bash`；启动命令**必须用绝对路径**；监听地址建议 `0.0.0.0`（不能 127.0.0.1）。

  `Nodejs20.19 → /var/lang/node20/bin/node`、`Nodejs16.13 → /var/lang/node16/bin/node`。
  → 运行环境选 **Node.js 18.15** 时启动文件必须写 `/var/lang/node18/bin/node index.js`（**两者要对应**）。
- ℹ️ 云函数「运行环境」创建后**不可修改**，所以启动文件里的版本路径必须一次写对。
